# The early Web, 1990–1993: information access versus source verification

**Source checked:** [CERN, A short history of the Web](https://home.cern/science/computing/the-birth-of-the-web/short-history-web/), institutional history, accessed 13 October 2026.

By the end of 1990, CERN reports that Tim Berners-Lee had a Web server and browser running. The project was announced more broadly in 1991; the first US Web server appeared at SLAC in December 1991. In 1993, the NCSA Mosaic browser helped widen access to the Web. CERN released the WorldWideWeb source code on a royalty-free basis on 30 April 1993.

These milestones help explain the movement from specialist information-sharing systems toward more accessible browsing. They **do not** show that people became more trusting, less skeptical, or better able to authenticate sources. A hyperlink allows navigation, not independent corroboration.

**Research question:** As interfaces made information easier to reach, did verification practices become easier, or did the appearance of an interconnected document acquire undeserved authority?

**Status:** Institutionally sourced historical chronology, not a behavioral experiment. Related: [earlier primary-source anchors](early-computing-primary-sources.md).
